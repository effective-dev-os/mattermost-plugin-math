# Stack

## Detected

- **Language:** Go (`go.mod`, module `github.com/effective-dev-os/mattermost-plugin-math`), Go 1.25
- **Server framework:** Mattermost plugin API (`github.com/mattermost/mattermost/server/public`), router `github.com/gorilla/mux`
- **Expression evaluation:** `github.com/expr-lang/expr` (>=v1.17.7) — see `.assistant/decisions.md` D-002 for version-pin rationale (two distinct DoS advisories) and the required input-normalization pass for human notation (`×`/`x`, unicode minus, comma decimals, implicit multiplication, `%`). `sin`/`cos` accept degrees, converted to radians before calling `math.Sin`/`math.Cos`.
- **Webapp:** TypeScript + React (`webapp/package.json`), Webpack build, Jest for tests, ESLint (`@mattermost/eslint-plugin`), `tsc` for type-checking. No UI planned for v1 — `@math` is a server-side message-hook trigger, not a slash command.
- **Build:** `Makefile`, Node v16 / npm v8 pinned via `.nvmrc`
- **Plugin id:** `dev.effective.math`

## @math mention trigger — implementation details

- **Message-hook trigger, not a slash command.** Implemented in `server/hooks.go` via the `MessageHasBeenPosted(c *plugin.Context, post *model.Post)` plugin hook on `*Plugin` (registered automatically by Go-method presence — no `plugin.json` capability/manifest key needed; the hook's own documented floor is server 5.2, well under the plugin's declared `7.1.0`, which is owned by `EnsureBot`, unchanged). No webapp-side registration or UI needed. `/math` slash-command registration and dispatch (formerly `server/command/`) has been removed entirely.
- **Mention detection:** `@math` must be the first OR last token of the (trimmed) message — case-insensitive, word-boundary aware of Mattermost's username charset (so `@math2` does not match; `what is @math 2+2`, a mid-message mention, is a silent no-op, not an error). See `.assistant/decisions.md` D-005 for the rationale: stripping a mid-message mention was found to produce silently-wrong results (e.g. `sqrt @math (4)` would evaluate to `2`, a result never intended) or unparseable ones (e.g. `2+2 @math 3+3`), so only the two unambiguous anchor positions are supported.
- **Guard chain** against self-reentrancy/loops, in order: (1) mention check first — cheap, no API calls, filters out the vast majority of posts before any Mattermost API call; (2) `post.GetProp(model.PostPropsFromPlugin) == "true"` check; (3) `pluginapi.Client.Post.ShouldProcessMessage(post, pluginapi.BotID(p.botUserID))` — the official Mattermost anti-loop helper, which skips the bot's own posts, system messages, webhook posts, and other bot accounts.
- **Expression evaluation:** unchanged — reuses `server/mathexpr` as-is (D-002/D-003 baseline: normalization pipeline, percent semantics, degrees for `sin`/`cos`, base-10 `log`, 1024-rune input cap, non-finite-result handling).
- **Reply:** `RootId` is `post.RootId` verbatim — a top-level mention (empty `RootId`) gets a plain reply in the channel; a mention already inside a thread stays in that thread. Formatted `` `<expr>` = `<result>` ``, authored by the bot account (`math`), via `client.Post.CreatePost`. A bare `@math` mention with no expression gets the same-placement usage-hint reply (`"Mention me with a math expression, e.g. \`@math 2 + 2\`."`) instead of an error. (D-005 originally threaded every reply unconditionally via `post.RootId` else `post.Id`; superseded by D-007 — see below.)
- **Errors are also a same-placement (non-ephemeral) bot reply**, not ephemeral. `MessageHasBeenPosted` has no HTTP-request-bound context to attach a guaranteed ephemeral response to — `SendEphemeralPost` called from this hook is a best-effort, unpersisted websocket broadcast that silently drops for disconnected/offline users. Non-ephemeral replies guarantee delivery like the success path, at the cost of being visible to the whole channel instead of just the asker (accepted trade-off, recorded in `.assistant/decisions.md` D-005).
- **Bot account:** username `math`, display name "Math" (changed from `math-bot` / "Math Bot" in D-007/D-008 — pre-release rename, no migration needed), still registered idempotently in `OnActivate` via `p.client.Bot.EnsureBot` (fails activation on error), avatar (`assets/math-bot-icon.png`) still set separately and non-fatally. Bot `Description` field: `"Posts results for @math mentions."`. `plugin.json`'s `min_server_version` stays `"7.1.0"` (unchanged — still required by `EnsureBotUser`, and the hook needs no higher floor).
